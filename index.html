★ Stars · деморежим
Платёж пока не подключён. Для настоящих платежей Telegram Stars нужен бот и серверный endpoint, который создаёт invoice link.
Как будет работать оплата
Пользователь нажимает «Открыть за Stars» → сервер создаёт счёт → Telegram показывает подтверждение → сервер проверяет successful_payment и открывает шаблон. Не доверяй оплате, подтверждённой только браузером.

Сейчас эта кнопка проверяет настроенный endpoint, но не списывает Stars и не создаёт настоящий платёж.

Реальная публикация не включится, пока серверный API не будет настроен. Токен бота хранится только на сервере, не в браузере.

Боту нужно выдать права администратора на публикацию в выбранном канале. Сервер должен проверять данные Telegram Web App и права пользователя.

Важно о безопасности
